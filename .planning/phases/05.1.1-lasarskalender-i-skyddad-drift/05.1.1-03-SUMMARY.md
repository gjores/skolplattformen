# Phase 05.1.1 Plan 03: Tracer utan migration och delade presentationsdelar Summary

**En lovdag går från klick i den skyddade vyn via set_days-kommando till mockat API och tillbaka, och demon och den skyddade vyn renderar nu samma kalender och samma presentationsdelar. Demon är exakt oförändrad mätt mot baslinjen.**

Allt UI-prov är **simulerat** mot ett mockat API i webbläsaren med en syntetisk skola (Syntetiska grundskolan, läsåret 2026/27). Ingen migration, ingen server, inget är installerat och ingen verklig anslutning är provad. Rutterna `/api/lasar/lasa` och `/api/lasar/kommando` finns ännu inte på servern (plan 06).
