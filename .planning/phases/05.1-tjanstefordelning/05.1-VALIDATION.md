# Fas 05.1 — Valideringsstrategi

> Underlag: [05.1-RESEARCH.md §Validation Architecture](05.1-RESEARCH.md). Gäller etapp 1.

## Testinfrastruktur

| Egenskap | Värde |
|----------|-------|
| **Ramverk** | `node:test` (Node 25, se minnesnotering om PATH), SQL-verifierare i ägd schemakopia (`work/pilot/verify-*.mjs`), pgTAP via `work/pilot/run-sql-tests.mjs`, Playwright (`web/e2e`) |
| **Konfiguration** | befintlig; nya `web/playwright.tjanst*.config.ts` skapas i provplanen |
| **Snabbkörning** | `cd web && node --test lib/tjanst*.test.mjs lib/server/tjanst*.test.mjs && npx tsc --noEmit` |
| **Full svit** | `cd web && node --test lib/*.test.mjs && npx tsc --noEmit && npx oxlint app lib && npm run build`; från roten `npm run docs:build` |
| **Ungefärlig tid** | snabb ~30 s, full ~5 min (utan faktiskt prov) |

## Provtakt

- **Efter varje uppgift:** snabbkörningen.
- **Efter varje våg:** full svit plus berörda SQL-verifierare.
- **Före `/gsd-verify-work`:** full svit, faktiskt Worker/OIDC-prov och browserprov på dator och telefon, alla PASS. Tidigare PASS i andra paket räknas inte.
