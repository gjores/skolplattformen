# 05.2-SM-BYT: Lediga lägen medan man drar, byt, lås och flera pass

**Status:** planerad 2026-11-13 (våg 4). Research D25, D26 (enkelt byte), L77, L78. Kedjebyten hör till SM-PLACERING.

## Mål

Medan ett pass dras eller flyttas med tangentbord syns direkt i veckan var det kan ligga. Två pass kan byta plats. Pass, dagar och en klass schema kan låsas och flyttas eller parkeras tillsammans.

## Designvy

`design/Main.dc.html` (verktygen Lås och Byt, passmenyns "Lås här (L)" och "Byt med ett annat pass… (B)", märkningen "Låst" i passrutan) och möjlighetskartans mönster och teckenförklaring i `design/Samlingsvy.dc.html` ("Samma färger visas i veckan medan ett pass dras").

## Blir sant

1. **Lediga lägen (D25):** när ett pass lyfts (pekare, tangentbord eller "Flytta…") hämtas lägen ur `/api/schema/lagen` och varje starttid i veckan färgas fri, önskemål, byte, brott eller spärrad med mönster. Starttiden under pekaren visar "Varför inte här?" i kort form. Släpp på brott är tillåtet som i dag och märks som regelavvikelse.
2. **Byt (D26):** verktyget Byt eller menyn "Byt med ett annat pass…": välj två pass → de byter dag och starttid (sal följer om den är ledig). Släpp ett pass på ett annat med verktyget Byt gör samma sak. Läget *byte* i kartan visar vilket pass som byts. Kontroll efteråt; ett steg i ångra.
3. **Lås (L78):** "Lås här", verktyget Lås, "Lås hela dagen" (dagrubrikens meny) och "Lås klassens schema". Låsta pass skickas som `locked` till motorn vid nästa beräkning och rörs inte; märkta "Låst" med text. Låsen ingår i förslagsbegäran (kontraktet höjs) och i utkastet.
4. **Flera pass (L77):** Skift-klick eller dra en ram med Markera väljer flera pass; flytta (samma förskjutning i tid), lås, lås upp eller parkera dem tillsammans; ett steg i ångra.

## Gränser

- Ingen motorsökning: kartans *byte* gäller ett enda pass (SM-LAGEN). Kedjor och "lägg med minsta störning" i SM-PLACERING.

## Prov

- `lib/schema-utkast.test.mjs`: byte och ångra; flytt av tre markerade pass; lås hela dagen.
- `lib/schema-underlag.test.mjs` + `verify-koppling.mjs`: låsta pass ligger kvar efter ny beräkning mot riktiga motorn; lås som omöjliggör förslaget ger motorns diagnos, inte tyst flytt.
- e2e (1280): dra ett pass och se färgerna (fri/brott) i veckan; tangentbordsflytt visar samma; byt två pass via meny; markera tre pass och parkera; lås klassens schema → nytt förslag ändrar inget för klassen.
