# Användarprov — valplaner, elevval och undervisningsgrupper

Installerat på 3012, kod `effdaa75f5`. Syntetiska data. Prova med rektorskontot och en skola och ett läsår där en godkänd gymnasietimplan har individuellt val.

| # | Gör så här | Ska hända | Resultat |
| --- | --- | --- | --- |
| U1 | Öppna **Valplaner**, skapa individuellt val, koppla raden, lägg till kurser och spara. | Valplanen sparas och timplanens rad hänvisar till den. | |
| U2 | Välj **Elevval**, ta ställning till vårdnadshavare, ange sista valdag och välj **Öppna val**. | Status visar öppet till datumet och klassens elever listas. | |
| U3 | Välj **Registrera val** för en elev, välj kurser som fyller poängen och spara. Bekräfta. | Spara går bara när poängen stämmer. Status blir Bekräftat. | |
| U4 | Koppla ett elevkonto och välj i **Mina val** på telefon. Ändra valet. | Eleven ser kurser och poäng kvar. Skolan ser Klart att bekräfta. | |
| U5 | Välj **Skapa grupper från valet** och öppna **Undervisningsgrupper**. | En grupp per kurs med bekräftade elever. Ny körning skapar inga dubbletter. | |
| U6 | Lägg till en parallell grupp, välj **Fördela jämnt** och flytta en elev. | Eleven byter grupp men har kvar sin klass. | |
| U7 | Öppna **Tjänstefördelning** och bemanna en grupp. | Gruppen är ett behov, och valplansraden räknas inte också som klassbehov. | |
| U8 | Ändra en grupps tid och försök publicera. | Raden blir inaktuell och stoppar publicering tills den sparats om. | |

Inloggad användning på 3012 är inte prövad av mig. U1–U8 är första provet med riktig inloggning och databas tillsammans.
