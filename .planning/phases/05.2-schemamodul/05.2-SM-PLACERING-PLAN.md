# 05.2-SM-PLACERING: Placeringsförslag och minsta störning

**Status:** planerad 2026-11-13 (våg 6). Research J62–J65 och D26 (kedja). Användarens önskemål 2026-11-13: hjälp när ett pass inte går att lägga.

## Mål

För ett pass som inte går att lägga, eller som ligger på viloytan, visar motorn de bästa sätten att få in det: direkt, med ett byte eller med en kort kedja av byten, med före och efter. Schemaläggaren kan också lägga ett pass där hen vill och låta motorn flytta det som krockar så lite som möjligt.

## Designvy

Möjlighetskartans mönster och "Varför inte här?" i `design/Samlingsvy.dc.html`; menypunkterna "Föreslå placering" och "Varför inte här?" i `design/Main.dc.html`. Förslagslistan har ingen egen skiss: bygg den som en lista med före/efter i samma radlayout som Följ passet (en rad per berört schema) och redovisa mönstret i SUMMARY och Skolplattan.

## Blir sant

1. `POST /v1/suggest` i tjänsten: underlag, placeringar, `lesson`, `depth` (1–3), låsta pass. Begränsad sökning (byten och ejection chains) med tidsgräns 2 s; svar: upp till fem förslag rangordnade efter kostnad, vart och ett med flyttade pass (från → till), berörda lärare och klasser, ändring i håltid och önskemål. Låsta pass och aktiviteter med fast tid rörs aldrig.
2. **Föreslå placering (J62):** från menyn, viloytan och Följ passet. Listan visar förslagen med antal flyttade pass och effekt; "Öka sökdjupet" kör om med större djup; ett klick genomför förslaget som ett steg i ångra.
3. **Lägg med minsta störning (J63):** dra passet till önskad tid med Alt (eller menyn "Lägg här och flytta det som krockar") → motorn flyttar krockande pass till närmaste lagliga plats med så få flyttar som möjligt (motorns `reference` och vikten `moved`). Visas som förslag före genomförande.
4. **Lägg viloytan (J64):** knappen på viloytan lägger alla parkerade pass och rör resten så lite som möjligt; förslaget visas före genomförande.
5. **Medvetna krockar (J65):** schemaläggaren kan behålla en krock som "medveten", märkt i passet och i Regelavvikelser; den följer med utkastet och kommer att spärra publicering (L2).

## Gränser

- Inga ändringar i underlaget (villkor, salar, tjänstefördelning): det är block K1.
- Inga förbättringar i bakgrunden (J67 → C1).

## Prov

- `cargo test`: pass som bara går in med ett byte ger det förslaget först; djup 2 hittar kedja där djup 1 inte gör det; låsta pass rörs aldrig; tidsgräns hålls.
- `verify-koppling.mjs`: förslag mot riktiga motorn ger 0 regelbrott efter genomförande; lägg viloytan flyttar färre pass än ny beräkning från noll på samma underlag.
- e2e (1280): parkera ett pass → Föreslå placering → genomför förslag 1 → ångra; Alt-dra till upptagen tid → förslag → genomför; medveten krock syns i listan.
