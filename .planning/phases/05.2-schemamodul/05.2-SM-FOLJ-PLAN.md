# 05.2-SM-FOLJ: Följ passet och möjlighetskartan

**Status:** klar 2026-11-14 ([SUMMARY](05.2-SM-FOLJ-SUMMARY.md)); planerad 2026-11-13 (våg 2). Research I52, I53, J61. Användarens önskemål 2026-11-13: se flera scheman samtidigt (som Skola24) och få hjälp när ett pass inte går att lägga.

## Mål

När ett pass markeras visas alla scheman det berör, rad för rad med gemensam tidsaxel, och överst en rad som visar var passet kan ligga och varför inte.

## Designvy

`design/Samlingsvy.dc.html` i sin helhet: rubriken "Följ passet: Matematik, Klass 1", chipsen för visade resurser, väljaren "Möjliga starttider räknas för: Alla berörda elever / Provelev 7", raderna (möjliga starttider, klass, lärare, sal, grupp som delar elever, elev), tooltipen "Varför inte tisdag 12:10?", elevradens krockmarkering och förklaringstexten, samt teckenförklaringen. Layouten: rad per resurs, kolumn per dag, dagens tid vågrätt.

## Blir sant

1. **Följ passet** öppnas från passmenyn (F), från verktyget Markera med dubbelklick och från knappen "Följ passet" vid markerat pass. Panelen visas under veckan och följer markeringen tills den låses ("Lås till detta pass").
2. **Rader:** klasserna och grupperna på passet, lärarna, salen, grupper som delar elever med passet (elevkluster ur `SchemaMembers`, med antal delade elever), och – för den som får se elever – en vald elev med schema ur klass och grupper. Elevens krockar som inte syns i klassens eller gruppens schema märks som i designvyn.
3. **Möjliga starttider** överst ur `/api/schema/lagen` med lägena fri, önskemål, byte, brott och spärrad i mönster enligt SM-YTA. Pekning eller fokus på en tid visar "Varför inte …?" med orsaker per resurs (`varfor` ur SM-LAGEN). Klick på en fri tid flyttar passet dit (samma flytt och kontroll som i dag).
4. **Elevnivå** byter möjlighetskartan till vald elev (`pupil`). Väljaren syns bara för behörig; annars bara "Alla berörda elever".
5. Panelen uppdateras efter varje flytt; lägen hämtas om med fingeravtrycket och avbryts om markeringen byts.

## Gränser

- Lägg till valfria resurser och spara arbetsvy hör till SM-SAMLINGSVY: chipsen visar här bara passets resurser, knapparna finns inte än.
- Ingen färgning i själva veckan medan man drar (SM-BYT).

## Prov

- `lib/schema-folj.test.mjs`: rätt resurser och kluster för ett pass med blockgrupp; elevens schema = klass + grupper; elevkrock som bara syns på elevnivå hittas.
- e2e (1280 och 1600, syntetiskt API med motorns riktiga lägessvar från `verify-koppling`-fixtur): följ ett pass med tangentbord, läs varför inte via fokus, flytta till fri tid, markering följer; utan elevbehörighet syns ingen elevväljare.

## SS 12000

Utanför standarden. Elevens schema härleds ur placeringar och medlemskap (`StudentGroup`-medlemskap med giltighet) men lagras inte.
