# UXF-54: Beräkningsläge medan schemamotorn räknar

**Mål:** Användaren önskade 2026-11-20 en animation som lägger sig över skärmen medan schemamotorn räknar. Den ska visa schemaläggningen och samtidigt hur långt beräkningen har kommit. Gäller **Ta fram schemaförslag** och **Fortsätt förbättra**.

**Gör:** Ett modalt beräkningsläge med appens `Dialog` öppnas när underlaget kontrolleras och när motorn räknar. Det öppnas inte under bekräftelsefrågan eller sparandet före beräkningen. Läget innehåller:

- överraden Schemamotorn, en rubrik och en text om vad som händer;
- en dekorativ minivecka (`aria-hidden`) som fylls med pass i takt med räknetiden, med en sökmarkör och enstaka byten;
- `Progress` med etiketten Räknetid och texten ”n av N sekunder”;
- stegen Kontrollerar underlaget, Lägger och förbättrar passen och Kontrollerar resultatet, med läget i text;
- knappen **Avbryt beräkningen** (outline). Esc gör samma sak, men ett klick utanför gör det inte.

Fokus hamnar på rubriken när läget öppnas. Efter ett nytt förslag går fokus till **Beräkning** och efter Fortsätt förbättra till granskningens rubrik. I övriga fall går det till knappen som startade beräkningen.

**Progressens betydelse:** Motorn söker hela den valda räknetiden (10, 30 eller 60 s) och skickar inget mellanläge (`schemamotor/crates/solve`). Förloppet visar förbrukad räknetid mätt i webbläsaren, inte andel lagda pass. Miniveckan är en illustration. Efter räknetiden visas Kontrollerar resultatet tills svaret kommer. Ett bevisat olösbart underlag kan bli klart tidigare.

**Avbryt:** Avbryt gör samma sak som **Behåll nuvarande schema** under Fortsätt förbättra. Webbläsaren slutar vänta och utkastet lämnas orört. Servern kan räkna klart den pågående omgången. Under tiden kan en ny start få beskedet att motorn redan räknar.

**Inte här:** mellanlägen från motorn (kräver strömmande svar eller jobbstatus), beräkningsläge i utlyfta fönster, korta motorkontroller vid flytt och placeringsförslag.

**Design:** Följer Skolplattan. Passen ritas som `schema-lesson` och sökmarkören som `schema-drop`. Lägen anges i text och Dialog, Progress och Button kommer från `components/ui`. Skolplattans README beskriver beräkningsläget som nytt mönster. Vid `prefers-reduced-motion` fylls veckan utan glidande markör och byten.

**Kontroller:** `npx tsc --noEmit`, `npx oxlint app lib`, `npm run build`, `npm run docs:build`. `npx playwright test -c playwright.schema.config.ts` körs med hela schemasviten på 1280 px och med `schema-berakning`, `schema-fortsatt` och `schema-uat-workflows` även på 1600 px. Visuell prövning på dator 1280 och 1600 px och vid 200 % text. Telefon prövas inte (undantag 2026-11-13).

**SS 12000:** Ingen ny data, inga objekt och inga identifierare. Läget visar bara ett pågående anrop och ligger utanför standardens omfattning.

**Utfall:** Byggt som planerat. Läget öppnas när underlaget kontrolleras och när motorn räknar ett nytt förslag eller fortsätter förbättra. Det öppnas inte under bekräftelsefrågan, sparandet eller **Kontrollera underlaget**. Efter Avbryt står ”Beräkningen avbröts. Utkastet är oförändrat.” Under Fortsätt förbättra gör Avbryt samma sak som **Behåll nuvarande schema**. Har arbetsytan redan flyttat fokus när läget stängs, till exempel till Före beräkning, Schemat kan inte läggas ännu eller granskningen, står fokus kvar där.

**Prov:** Åtta nya Chromiumfall i `schema-berakning` passerade på 1280 och 1600 px, också med rörelse påslagen och vid 200 % text. Avbrottsprovet i `schema-fortsatt` använder nu lägets **Avbryt beräkningen**. Hela schemasviten på 1280 px gav 197 godkända och 8 underkända fall. De åtta underkänns likadant på ren HEAD `02acf981` och hör inte till denna plan:

- provplanens andra `alert` i förhandsvisningen (fem fall);
- marginaler (ett fall);
- märkningen ”Ligger på spärrad tid” (två fall).

`schema-berakning`, `schema-fortsatt` och `schema-uat-workflows` passerade även på 1600 px (29 fall). Typkontroll, lint, appbygge och handboksbygge passerade. Skolplattans README har avsnittet Beräkningsläge (version 38).

**Återstår:** Installation på 3012, inloggat prov mot verklig motor och användarprov.
