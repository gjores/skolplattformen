# UXF-12: Tid, sal och kapacitet var för sig

**Mål:** Statusen "Alla pass lagda" ersätts av tre besked med egen betydelse (nulägesfynd P1 nr 2).

**Gör:** `schemaLage(forslag)` räknar: pass med tid av alla; pass med sal av de pass som ska ha sal; pass utan besvarat salbehov; kapacitet kontrollerad, för liten eller inte kontrollerad. Vyn visar tre statusbrickor med text, aldrig en samlad klarstatus. Motorns status (räknetiden tog slut, går inte att lägga) står kvar som eget besked.

**Blir sant:** ett förslag där alla pass har tid men inga salar visar "Tid: alla pass har tid" och "Sal: salbehov saknas för N pass", inte grönt klart.

**Kontroller:** `node --test lib/schema-status.test.mjs`; berörda e2e-texter uppdateras och körs; handbokens schemasida och `npm run docs:build`.
