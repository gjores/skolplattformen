# UXF-42: Sammanhängande möjlighetskarta och läsbar inspektör

**Mål:** Ett klick på ett pass visar passet; flytt är en uttrycklig handling. Möjlighetskartan ritar sammanhängande lägesfält i stället för fem minuter höga rutor (nulägesfynd P1 nr 5, `Veckan2.dc.html`).

**Gör:**
1. Inspektör bredvid veckan: pass, tid, deltagare, sal, salbehov, lås, källa, valt läges orsaker, och knapparna Flytta, Byt sal, Lås, Parkera, Följ passet. Vid 200 % text flyttar den under veckan.
2. Lägen med samma status slås ihop till ett fält per sträcka; exakt start väljs i inspektören med stegning om fem minuter och 44 px-knappar. Fältets text säger aldrig mer än det som gäller hela sträckan.
3. Tangentbord och snabbverktyg behåller dagens beteende.

**Blir sant:** klick ändrar ingenting i utkastet; exakt flytt till 10:35 går utan dragning.

**Kontroller:** `npx playwright test -c playwright.schema.config.ts schema-inspektor schema-byt schema`; `node --test lib/schema-lagen.test.mjs`.

**SS 12000:** utanför standarden (visning).
