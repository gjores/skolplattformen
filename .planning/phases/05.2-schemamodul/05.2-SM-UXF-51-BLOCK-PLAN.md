# UXF-51: Egna samtidighetsblock

**Mål:** Utvalda veckopass från olika undervisningar kan bindas till samma start, även utanför valmodulerna (nulägesfynd P1 nr 3, researchens Kompletterande genomgång). Varje pass behåller sina deltagare, lärare, sal och minuter.

**Gör:**
1. Valfritt villkorsfält `block`: namn och medlemmar `{ ref, term, pass }` (undervisningens referens, termin eller `null`, passets nummer inom undervisningen, samma numrering som villkor för enskilda pass). Blocken ingår i grunden: en ändring kräver nytt förslag.
2. `schemaBlock`: medlemmarna slås upp i underlaget. Ett block med pass som inte längre finns är **inaktuellt** (till exempel efter ändrat lektionsantal). **Hinder**: olika terminer, samma lärare i två pass, samma elever i två pass. Olika längd är tillåtet: passen börjar samtidigt och slutar olika (motorprovet visar det; researchens påstående om samma längd stämmer inte för dagens motor). Block som delar pass slås ihop till en samtidighetsgrupp och redovisas så. Bara block utan hinder blir motorns koppling `simultaneous`.
3. Status per block i förslagets svar och i fördiagnosen (`block_hinder`, `block_inaktuellt`).
4. Förbered › Lektioner och block: lista med status, formulär för nytt block (namn, välj pass), ta bort. "Samma slut" erbjuds inte.

**Blir sant:** två pass med olika lärare och elever i ett block får samma start i motorns svar; ett block där en lärare finns i två pass används inte och namnger läraren.

**Utfall:** byggt som planerat. Olika längd är tillåtet (motorprov `own_blocks.rs`). Förslagets pass bär nu `undervisning` och förslaget `block` med status; kontraktsversionen är oförändrad (A3). Med ett lagt förslag visar ett nytt block "Inte prövat ännu" tills ett nytt förslag räknats. Inget motorbyte behövs: kopplingen `simultaneous` finns i installerad motor.

**Kontroller:** `node --test lib/schema-block.test.mjs lib/schema-underlag.test.mjs`; `cargo test --release -p schemamotor-solve` (nytt prov för egen koppling); `npx playwright test -c playwright.schema.config.ts schema-block`.

**SS 12000:** egna block är ett internt planeringsbegrepp utanför standarden. De skapar inga nya grupper (`StudentGroup`) eller aktiviteter (`Activity`) och ändrar inga undervisningsminuter.
